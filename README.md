# 智能意图路由

群聊里的消息大部分不是在跟你说话。这个插件用一个便宜的判断模型给每条消息打分，
**只把值得回的放给主人格**；偶尔遇到特别好的梗，才会以极低的概率插一句。
零触发词、可批量、可缓存。

## 安装

1. 把 `astrbot_plugin_intent_router` 放进 AstrBot 的 `data/plugins/`，重载插件。
2. 在插件配置里填一个**判断用模型**（建议单独建一个便宜 Provider，和主人格分开）、
   机器人名字 / 别名、以及一句话人设。
3. 在群里发一条不希望它插话的闲聊，再发一句「@她」的话，看日志里的判定流水。
4. 想调参就看网页看板：插件详情页 → **意图路由看板**。

不装「虚拟世界」也能跑：意愿值用固定值（默认 0.55）。装了之后自动接上，
意愿由她当时的状态决定。

## 它怎么判

```
消息进来
  → 安全层（屏蔽词/正则/超长）拦掉
  → 规则层：@ 她、叫她名字、命令 → 直接放行，不花判断的钱
  → 噪音层：纯表情、复读、太短、纯链接 → 直接丢掉
  → 判断模型：worth / reply_score / rare_interject_score / confidence / risk …
  → 决策层：
        worth=true            → 放行（意愿太低就排队延迟，不拒绝）
        worth=false 但好梗      → 硬熔断 + 极低概率插一句（上限 8%）
        其它                   → 安静
```

密度控制不用固定窗口计数，而是**多尺度时间衰减**（5 分钟 / 30 分钟 / 6 小时半衰期混合）
再按群活跃度归一化：冷群几乎不惩罚，话密的时候自动收敛。她说过的话由**发送层钩子**
统一记录，不管是谁发的都算她开口。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/router stats` | 看当前群近 24 小时的判断、放行、插嘴、熔断统计 |
| `/router on` / `/router off` | 开关插件（管理员） |
| `/router good <id>` / `/router bad <id>` | 标记某条判断对不对（管理员） |

## 网页看板

插件详情页里的 **意图路由看板**：

- 概览：判决条数、放行 / 插嘴 / 熔断、判断调用与缓存命中、token 用量、误判标记
- 分布：她此刻的意愿分布、密度惩罚分布
- **判定流水**：每条消息的分数、概率分解、最终决策、理由，并可当场标 👍/👎
- **核心参数**：概率上限、好梗门槛、熔断线、半衰期与权重、VM 超时与熔断……
  改完立刻生效（存进 `overrides.json`），也能一键恢复默认
- 数据：导出 JSON、按保留天数清理、清空记录

## 与「虚拟世界」联动

只依赖她暴露的意愿值（`social_snapshot` 或 `reply_willingness`）：

- 她在那个世界里睡觉 → 本插件完全不判断、不回应；
- 意愿高 → 更容易放行、更容易偶尔插一句；意愿过低 → 放行也会排队延迟、插嘴直接归零；
- VM 超时（默认 0.5s）、返回异常、连续失败 5 次 → 回落到固定意愿并暂停联动 60 秒，
  恢复后自动接上。**判断永远不会因为 VM 出问题而卡住。**

## 数据

都在 AstrBot 的 `data/plugin_data/astrbot_plugin_intent_router/`：

| 文件 | 内容 |
| --- | --- |
| `router.db` | 她说过的话 + 每次判定流水（默认保留 30 天） |
| `overrides.json` | 看板里改过的核心参数 |
| `runtime.json` | 看板上的开关状态 |

## 常见问题

**她一句话都不说了？** 先看判断模型能不能用（`/router stats` 里的判断调用数），
再看 `fail_mode`：默认是 `block`（判断失败就不回）。想"宁可多说"改成 `pass`。

**她太爱插嘴了？** 把「主动插嘴」开关关掉，或把 `rare_threshold` 提到 0.95、
把 `hard_cap` 压到 0.03。

**她该回的不回？** 看判定流水里那条的 `reply_score` 和 `confidence`，
多半是人设/群规没写清楚——把「什么情况下该接话」写进配置里的"简略人设"。
